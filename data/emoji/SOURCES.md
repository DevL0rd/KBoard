# Emoji data sources

`emoji.json` is generated by `generate.py` (run `python3 data/emoji/generate.py`). It keeps fully-qualified emoji only, with group, subgroup, name, keywords, Unicode emoji version and the five uniform skin tone variants where they exist.

| File | Source | Version | Licence |
| --- | --- | --- | --- |
| `emoji.json` groups, names, order, versions, skin tones | Unicode `emoji-test.txt`, https://unicode.org/Public/18.0.0/emoji/emoji-test.txt | Emoji 18.0 | Unicode License v3 (https://www.unicode.org/license.txt) |
| `emoji.json` keywords | Unicode CLDR English annotations, npm `cldr-annotations-full` and `cldr-annotations-derived-full` (`annotations/en`, `annotationsDerived/en`) via cdn.jsdelivr.net | CLDR 48.2.0 | Unicode License v3 (https://www.unicode.org/license.txt) |
| `emoji.json` `popular` ranking | Curated for KBoard | | Same as KBoard |
| `kaomoji.json` | Curated for KBoard | | Same as KBoard |

Emoji that the installed Noto Color Emoji font cannot draw are hidden at runtime.
