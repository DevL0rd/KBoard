## Libraries used at run time

These are linked from your system and not redistributed. On distros without a
whisper.cpp that has Parakeet support, the build downloads the pinned whisper.cpp
release (https://github.com/ggml-org/whisper.cpp, MIT) and links it and its ggml
into KBoard.

| Library | Used for | Licence |
| --- | --- | --- |
| whisper.cpp and ggml | Speech recognition for voice typing | MIT |
| SDL3 | Game controller input | Zlib |
| Hunspell | Spell checking and word validation | MPL-1.1 / GPL-2.0-or-later / LGPL-2.1-or-later |
| Qt 6 | Application framework | LGPL-3.0-only / GPL-2.0-only / GPL-3.0-only |
| KDE Frameworks 6 | Configuration, i18n, Kirigami and desktop integration | LGPL-2.0-or-later and compatible |

## Models

### NVIDIA Parakeet TDT 0.6B v3

The default voice typing model, downloaded on install in GGUF form.

- Original model: https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3
- GGUF conversion: https://huggingface.co/ggml-org/parakeet-GGUF
- Licence: CC-BY-4.0 (https://creativecommons.org/licenses/by/4.0/)
- Attribution: NVIDIA Corporation

### OpenAI Whisper

Optional voice typing models for other languages, downloaded on request.

- GGML conversions: https://huggingface.co/ggerganov/whisper.cpp
- Licence: MIT

`data/emoji/emoji.json` is generated by `data/emoji/generate.py` from the

- Sources: https://unicode.org/Public/emoji/ and https://github.com/unicode-org/cldr-json
- Licence: Unicode License v3 (https://www.unicode.org/license.txt)

- `en.ngram`: Tatoeba contributors, CC-BY 2.0 FR
